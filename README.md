# 🍔 Food Store - Sistema Full-Stack

Aplicación web Full-Stack desarrollada para la gestión integral de una tienda de comidas. Este proyecto implementa una arquitectura desacoplada con un backend robusto basado en persistencia de datos y una interfaz de usuario moderna y responsiva.

---

## 🛠️ Tecnologías Utilizadas

### Backend
* **Lenguaje:** Java
* **Persistencia:** JPA (Java Persistence API)
* **Construcción y Dependencias:** Gradle

### Frontend
* **Framework:** React
* **Tipado:** TypeScript
* **Estilos:** Tailwind CSS

---

## 📂 Estructura del Repositorio

FoodStore-FullStack/
├── backend/       # Código fuente del servidor, modelos JPA y configuración de Gradle
└── frontend/      # Interfaz web en React, componentes y vistas de administración/cliente

---

## 🚀 Guía de Ejecución Local

### 1. Backend (Java / Gradle)
1. Navegá a la carpeta del servidor:
   `cd backend`
2. Ejecutá el proyecto utilizando Gradle:
   `./gradlew run`

### 2. Frontend (React / Vite / TypeScript)
1. Navegá a la carpeta del cliente:
   `cd frontend`
2. Instalá las dependencias:
   `npm install`
3. Iniciá el servidor de desarrollo local:
   `npm run dev`
